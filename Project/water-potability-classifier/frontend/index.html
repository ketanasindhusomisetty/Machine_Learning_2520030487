Evaluation Metric Note

Why MSE and MAE are not shown as model-performance metrics.

Classification Task The target is binary: Potable (1) or Not Potable (0).
Primary Metrics Accuracy, Precision, Recall, F1-Score and ROC-AUC are used.
MSE / MAE These are primarily regression error metrics and are not used as the primary evaluation here.
